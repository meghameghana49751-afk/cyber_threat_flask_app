Cyber Threat Prediction and Assessment Using Machine Learning

Project Overview

This project aims to predict and assess potential cyber threats using Machine Learning techniques. It analyzes suspicious IP addresses, network traffic, and attack patterns to identify potential security risks.

Technologies Used

- Python
- Flask
- Machine Learning
- K-Means Clustering
- Gaussian Mixture Model (GMM)
- HTML, CSS, JavaScript
- SQLite

Key Features

- Cyber threat prediction
- Suspicious IP address analysis
- Network activity monitoring
- Threat assessment
- Web-based dashboard
- Prediction results visualization

Algorithms

- K-Means Clustering
- Gaussian Mixture Model

Project Objective

To identify suspicious activities and improve cybersecurity by using machine learning approaches.
